# بروف دفتر - Proof Daftre
## المطور: Professor

- **اسم التطبيق:** بروف دفتر / Proof Daftre
- **المطور:** Professor
- **الإصدار:** 1.0.0
- **الوصف:** نظام محاسبي شامل لإدارة أسناد الصرف والقبض والحسابات والتقارير - تخزين لا نهائي محلي يدعم 50,000+ سند مع صور
- **المنصة:** أندرويد + ويب
- **التخزين:** محلي 100% غير محدود حسب ذاكرة الهاتف
- **الشعار:** Shield مع كتاب وعلامة صح (أزرق)

### الأيقونات:
- `public/logo.png` - الشعار الأصلي
- `public/icon-*.png` - أيقونات الويب
- `public/icons/` - جميع الأحجام
- `icons/android/` - أيقونات أندرويد جاهزة للنسخ إلى `android/app/src/main/res/`

### للبناء:
```bash
npm install
npm run build
npx cap add android
# انسخ الأيقونات:
cp -r icons/android/* android/app/src/main/res/
npx cap sync android
npx cap open android
```

### معلومات المتجر:
- اسم التطبيق: بروف دفتر
- اسم قصير: Proof Daftre
- المطور: Professor
- الفئة: Finance / Productivity
- الوصف القصير: نظام محاسبي محلي لا نهائي
- الوصف الطويل: نظام بروف دفتر المحاسبي الشامل مع تخزين لا نهائي محلي حسب ذاكرة هاتفك، يدعم حتى 50,000 سند مع صور بدون أي بطء، يعمل بدون إنترنت 100% في صنعاء وأي مكان.
